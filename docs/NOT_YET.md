# EH3D-DESIGN-HISTORY: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Merging of branches | Branch comparison is a job for the design explorer | the design explorer has its first version |
| A history stored in a database | A JSON file next to the project is enough for the sizes the limits allow | a project history grows beyond the size limit |
| Signed histories | A signature needs a key policy that nobody has decided, and no key is ever stored in a repository | the passport records its first signature |
| Semantic comparison of two designs without their history | It needs a reader of the design, which belongs to the design tool | the design tool exposes its model to the engines |
| A task kind for the server | The server has no kind of task for a history yet | the server accepts tasks from the engines |
